# Exercise integration draft
Exercise 03 synchronous chat uses the authenticated Package 01 service. The LIVE_CHAT_ENABLED environment flag defaults to false. Do not enable until cloud tests of quotas, ownership, persistence, model settings and error handling pass. Existing demo panels are retained. Streaming, async and concurrency comparisons are pending. Exercise 04-06 panels are planning placeholders, not working inference or training implementations. File/web tools require separate controlled routing and cost validation; fine-tuning and safety configuration require separate service checks. No cloud resources are created by this package.
