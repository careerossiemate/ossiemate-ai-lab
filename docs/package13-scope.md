# Package 13: controlled platform automation
- Existing develop deployment only. Cost API uses the runtime managed identity and five fixed resource-group scopes. No inference or new paid services. Costs are delayed and may include other workloads in those groups; no currency conversion or hard cap.
- Optional cost access: the release script offers a separate COST-READ confirmation to grant Cost Management Reader on those five groups only. Requires role assignment privileges and supported billing scope. No subscription-wide grant.
- GitHub deployment is manual and disabled by default. Configure a dedicated Entra workload identity (not the runtime identity), federated subject `repo:careerossiemate/ossiemate-ai-lab:environment:ai103-develop`, issuer `https://token.actions.githubusercontent.com`, audience `api://AzureADTokenExchange`. Assign AcrPush on the existing ACR (legacy registry permissions) and Container Apps Contributor on the existing app only. Confirm role availability and access. Configure GitHub environment ai103-develop restricted to develop, with required approval if supported. Set environment variables AI103_AZURE_CLIENT_ID, AI103_AZURE_TENANT_ID, AI103_AZURE_SUBSCRIPTION_ID and finally AI103_DEPLOY_ENABLED=true. No client secret. No automatic identity or role creation for deployment in this release.
- Workflow dispatch requires current image digest and DEPLOY-DEVELOP. It builds, pushes, checks current image again, deploys, checks readiness and anonymous rejection, requests rollback on failure. Manual and local deployments must not overlap. Cancellation/runner loss may require manual rollback. After workflow deployment, run the release script with -ReconcileLifecycle from a clean develop checkout to refresh local state; review and commit the lifecycle digest change. Do not stop/delete runtime before reconciliation. Recreated app may need app-scoped role reassignment.
- Bicep templates are reference only, not complete IaC or applied. Existing services and environment settings remain unchanged. No preprod/prod deployment.
- Tests cover pure cost parsing only; live cost, OIDC, Bicep compilation/what-if and authenticated AI tests remain pending. Native AI backlog remains open (see previous scope files).
