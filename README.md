# Ossiemate AI Showcase Portal

## Project Overview
An Azure-hosted AI showcase platform demonstrating practical
Microsoft AI-103 implementations.

## Exercise Modules
- Exercise 03 - Conversational AI
- Exercise 04 - File Search and Web Search
- Exercise 05 - Model Fine-tuning
- Exercise 06 - Responsible AI and Guardrails

## Technology Stack
- Python and FastAPI
- Azure Static Web Apps
- Azure Container Apps
- Microsoft Foundry
- Azure Blob and Table Storage
- Azure Container Registry
- Azure Managed Identity
- Azure Bicep
- GitHub Actions

## Deployment Strategy
- develop: Development and exercise implementation
- preprod: Integration and deployment validation
- main: Production showcase portal

## Infrastructure Lifecycle
- Permanent showcase website
- Persistent data and exercise progress
- On-demand Python backend
- Automated deployment and deletion
- No virtual machines
